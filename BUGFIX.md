# Баги

Запускал на vite, потыкал руками, вот что нашёл

1. Состояние хранилось в обычных let переменных (selectedServices, selectedServiceId, quantity)
   прямо в теле компонента. После любого клика эти переменные просто создавались заново с пустыми
   значениями и перерисовки не происходило, таблица не появлялась, итог всегда 0.
   Перенёс всё в useState.

2. Дальше всё равно не работало потому что в addService и removeService массив мутировался
   напрямую (push, splice, quantity +=). React сравнивает ссылки и обновления не было.
   Переписал на map и filter, объекты копирую через spread.

3. find(s => s.id === selectedServiceId) — selectedServiceId объявлен как number | string = '',
   то есть сравнивается число со строкой, по этому если значение осталось строкой услуга
   не находилась. Сделал тип number | '' и проверку в начале функции, плюс везде сравниваю
   по id а не по ссылке на объект.

4. min и max на инпуте с количеством не запрещают вводить мусор, можно ввести 0 или пустоту
   (Number('') это 0) и итог портится, иногда NaN. Добавил обрезку значения в onChange от 1 до 10.

5. После добавления select и количество не сбрасывались, повторный клик тихо менял количество
   уже добавленной услуги. В конце addService сбрасываю выбранный id и колличество.

Проверка: npm install, npm run dev. Добавляем услугу, меняем количество, удаляем строки, итог
считается правильно и дубликатов нет.
